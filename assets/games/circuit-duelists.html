Μέγεθος / Ιδιότητα Σύνδεση σε Σειρά Παράλληλη Σύνδεση
Ένταση Ρεύματος (I) Iολ = I₁ = I₂ (ίδια παντού — καμία «πτώση έντασης») Iολ = I₁ + I₂ και I₁ / I₂ = R₂ / R₁
Πτώση Τάσης (V) Vπηγ = V₁ + V₂ και V₁ / V₂ = R₁ / R₂ V₁ = V₂ = Vπηγ (κοινή τάση)
Ισοδύναμη Αντίσταση (Rολ) Rολ = R₁ + R₂ (μεγαλώνει) Rολ = (R₁ · R₂) / (R₁ + R₂) (μικρότερη από τη μικρότερη)
Ισχύς (P) & Ενέργεια (E) P₁ / P₂ = E₁ / E₂ = R₁ / R₂ (ανάλογα του R) P₁ / P₂ = E₁ / E₂ = R₂ / R₁ (αντίστροφα του R)
Αποσύνδεση Αντιστάτη Διακόπτεται όλο το κύκλωμα (I = 0 A) Ο άλλος κλάδος λειτουργεί κανονικά

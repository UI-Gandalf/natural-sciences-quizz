# Τεχνική Τεκμηρίωση & Οδηγός Ανάπτυξης
### Γυμνάσιο Νέας Ερυθραίας - Φυσικές Επιστήμες (Quiz Platform)

Αυτό το έγγραφο περιγράφει την τεχνολογική αρχιτεκτονική, τη δομή αρχείων, τη διαδικασία δημοσίευσης και τις βέλτιστες πρακτικές επέκτασης της πλατφόρμας.

---

## 1. Τεχνολογική Στοίβα (Tech Stack)

Η εφαρμογή είναι σχεδιασμένη ως **Client-Side SPA (Single Page Application)** με στόχο τη μηδενική συντήρηση, μέγιστη ταχύτητα και πλήρη ανεξαρτησία:

* **HTML5**: Σημασιολογική δομή (Semantic HTML), προσβασιμότητα και υποστήριξη οθονών αφής.
* **Vanilla CSS3**: 
  - Σχεδιασμός Glassmorphism (ημιδιαφανείς κάρτες, frosted blur εφέ).
  - Πλήρες σύστημα μεταβλητών CSS (`:root` / `[data-theme="light"]`) για Dark και Light themes.
  - Responsive Grid & Flexbox διατάξεις.
  - Εργονομική μπάρα πλοήγησης αντίχειρα (`.actions-bar`) για οθόνες κινητών ($\le 640\text{px}$).
  - `touch-action: manipulation` για αποτροπή καθυστερήσεων 300ms στα smartphones.
* **Vanilla JavaScript (ES6+)**:
  - Μηχανή δρομολόγησης βασισμένη σε Hash URL (`#/class/:id/subject/:sub/quiz/:qid`).
  - Πλήρης διαχείριση κατάστασης (`AppState`) χωρίς εξωτερικές βιβλιοθήκες.
  - Δυναμική εναλλαγή φόντου (`updateDynamicBg`) με crossfade transition ανάλογα με το μάθημα.
  - Σύστημα τυχαιοποίησης / επαναφοράς ερωτήσεων με ουρά παράλειψης (Pass queue).

## 3. Φιλοξενία στο GitHub Pages

Η πλατφόρμα φιλοξενείται απευθείας στο GitHub Pages χωρίς την ανάγκη build step:

1. **Σχετικά Paths**: Όλοι οι σύνδεσμοι εικόνων, CSS και JS χρησιμοποιούν σχετικές διαδρομές (π.χ. `assets/images/...`), ώστε η σελίδα να λειτουργεί απρόσκοπτα τόσο τοπικά όσο και κάτω από το path υποφακέλου (`https://<username>.github.io/<repo>/`).
2. **Αρχείο `.nojekyll`**: Απαραίτητο στο root directory ώστε το GitHub Pages να μην αγνοεί φακέλους ή αρχεία που ξεκινούν με κάτω παύλες.
3. **Cache-Busting**: Στο `index.html` οι κλήσεις των αρχείων περιλαμβάνουν query version (`styles.css?v=16`, `app.js?v=16`) για άμεση ανανέωση του browser cache σε κάθε αναβάθμιση.

### Ενεργοποίηση:
* GitHub Repo ➔ **Settings** ➔ **Pages** ➔ **Source**: `Deploy from a branch` ➔ **Branch**: `main` / `(root)`.

## 4. Προσθήκη Νέων Κουίζ & Μαθημάτων

Όλο το περιεχόμενο των κουίζ βρίσκεται συγκεντρωμένο στο αρχείο [`js/quiz-data.js`](../js/quiz-data.js):

### Δομή Αντικειμένου Ερώτησης:
```javascript
{
    id: 1,
    question: "Ποια είναι η μονάδα μέτρησης της έντασης του ηλεκτρικού ρεύματος στο S.I.;",
    options: [
        "Το 1 Volt (V)",
        "Το 1 Ampere (A)",
        "Το 1 Ohm (Ω)",
        "Το 1 Watt (W)"
    ],
    correct: 1, // Δείκτης της σωστής απάντησης (0 = πρώτη επιλογή)
    hint: "Σκεφτείτε το όνομα του Γάλλου φυσικού André-Marie...",
    explanation: "Η μονάδα μέτρησης της έντασης του ηλεκτρικού ρεύματος στο Διεθνές Σύστημα (S.I.) είναι το Ampere (A), προς τιμήν του André-Marie Ampère."
}
```

Για ενεργοποίηση μαθήματος που βρίσκεται «Υπό Προετοιμασία» (π.χ. Βιολογία ή Γεωγραφία), αλλάζουμε το `isPlaceholder: false` και καταχωρούμε τον πίνακα ερωτήσεων στο αντίστοιχο αντικείμενο του `QUIZ_DATABASE`.

## 5. Κρυπτογραφική Προστασία Απαντήσεων & Obfuscation (Υλοποιημένο)

Η πλατφόρμα ενσωματώνει πλήρες αυτοματοποιημένο σύστημα προστασίας:

### Πώς λειτουργεί:
1. **Αρχείο Ανάπτυξης (`src/quiz-data.dev.js`)**:
   - Εδώ ο καθηγητής επεξεργάζεται τα θέματα με ανθρώπινη αρίθμηση (`"correct": 1`, `"correct": 2`).
   - Το αρχείο αυτό προστατεύεται από το `.gitignore` και **δεν ανεβαίνει ποτέ στο δημόσιο GitHub**.
2. **Script Προστασίας (`protect.py`)**:
   - Εκτελώντας απλώς `python protect.py`:
     - Όλες οι σωστές απαντήσεις μετατρέπονται αυτόματα σε salted SHA-256 hashes (`"correctHash": "..."`).
     - Αφαιρείται κάθε αναφορά σε plaintext απάντηση (`"correct": X`).
     - Γίνεται Minification (αφαίρεση σχολίων και περιττών κενών).
     - Ανανεώνεται αυτόματα η έκδοση cache (`?v=...`) στο `index.html`.
     - Το τελικό προστατευμένο αρχείο αποθηκεύεται στο `js/quiz-data.js` και είναι έτοιμο για push.
3. **Έλεγχος στον Περιηγητή (`js/app.js`)**:
   - Ο έλεγχος της απάντησης γίνεται μέσω της ενσωματωμένης σύγχρονης συνάρτησης `sha256()`.
   - Το salt είναι κωδικοποιημένο σε Base64 (`atob()`).
   - Ακόμα και αν ένας μαθητής ανοίξει τα Developer Tools (`F12`), είναι αδύνατο να βρει τη σωστή απάντηση.

## 6. Συντομεύσεις Πληκτρολογίου (Keyboard Accessibility)

Η εφαρμογή υποστηρίζει πλήρη χειρισμό από το πληκτρολόγιο:
* <kbd>1</kbd> έως <kbd>5</kbd>: Επιλογή απάντησης (Α έως Ε)
* <kbd>H</kbd>: Εμφάνιση / Απόκρυψη υπόδειξης (Hint)
* <kbd>Enter</kbd>: Επιβεβαίωση απάντησης / Μετάβαση στην επόμενη ερώτηση
* <kbd>P</kbd>: Προσωρινή παράλειψη ερώτησης (Pass)
* <kbd>Esc</kbd>: Έξοδος από το κουίζ (με παράθυρο επιβεβαίωσης)

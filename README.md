## 📖 Τι είναι αυτή η πλατφόρμα;

Η πλατφόρμα δημιουργήθηκε για να προσφέρει στους μαθητές έναν αυτόνομο, ευχάριστο και ουσιαστικό τρόπο μελέτης:
* **Αυστηρά βασισμένη στη διδακτέα ύλη**: Όλες οι ερωτήσεις προέρχονται από τα επίσημα σχολικά φυλλάδια αυτοαξιολόγησης και τις παραδόσεις του μαθήματος.
* **Χωρίς εγγραφή ή κωδικούς**: Ανοίγει άμεσα στον browser χωρίς να χρειάζεται δημιουργία λογαριασμού ή εγκατάσταση εφαρμογής.
* **Σεβασμός στην ιδιωτικότητα**: Δεν αποθηκεύονται προσωπικά δεδομένα.

---

## ✨ Πώς σε βοηθάει στη μελέτη σου;

* 🎯 **Άμεση Επεξήγηση σε κάθε απάντηση**: Μόλις επιλέξεις μια απάντηση, μαθαίνεις αμέσως αν είναι σωστή και διαβάζεις την αναλυτική επιστημονική αιτιολόγηση για να κατανοήσεις τη λύση.
* 💡 **Διδακτικές Υποδείξεις (Hints)**: Αν δυσκολεύεσαι σε μια ερώτηση, πάτησε το κουμπί της *Υπόδειξης* για να σε κατευθύνει στο σωστό σκεπτικό χωρίς να σου αποκαλύψει τη λύση.
* ⏭️ **Μηχανισμός Παράλειψης (Pass)**: Μπορείς να παραλείψεις μια δύσκολη ερώτηση και να συνεχίσεις. Η εφαρμογή θα στη φέρει ξανά αυτόματα στο τέλος του τεστ.
* 📊 **Αναλυτική Καρτέλα Επανάληψης (Review Screen)**: Στο τέλος κάθε κουίζ βλέπεις το σκορ σου, ποιες ερωτήσεις απάντησες σωστά με την πρώτη φορά και συγκεντρωτικό πίνακα με όλες τις λύσεις για αποτελεσματική επανάληψη.
* 🌙 **Dark & Light Mode**: Επίλεξε σκοτεινό ή φωτεινό θέμα με ένα κλικ (κουμπί 🌙 / ☀️ πάνω δεξιά) για ξεκούραστη μελέτη.

## 📱 Οδηγίες Χρήσης

### Από Smartphone ή Tablet:
* Η εφαρμογή είναι ειδικά βελτιστοποιημένη για οθόνες αφής.
* Τα κουμπιά πλοήγησης (*💡 Υπόδειξη*, *Παράλειψη*, *Επόμενο*) βρίσκονται καρφιτσωμένα στο κάτω μέρος της οθόνης για εύκολο πάτημα με τον αντίχειρα.

### Από Υπολογιστή (Συντομεύσεις Πληκτρολογίου):
* <kbd>1</kbd> έως <kbd>5</kbd>: Άμεση επιλογή απάντησης (Α έως Ε)
* <kbd>H</kbd>: Εμφάνιση / Απόκρυψη υπόδειξης (Hint)
* <kbd>Enter</kbd>: Επιβεβαίωση απάντησης / Μετάβαση στην επόμενη ερώτηση
* <kbd>P</kbd>: Παράλειψη ερώτησης
* <kbd>Esc</kbd>: Έξοδος από το κουίζ

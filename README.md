# Γυμνάσιο Νέας Ερυθραίας - Φυσικές Επιστήμες
### Διαδραστική Πλατφόρμα Αυτοαξιολόγησης & Εξάσκησης

Μια σύγχρονη, ταχύτατη διαδικτυακή πλατφόρμα διαδραστικών κουίζ και αυτοαξιολόγησης, σχεδιασμένη ειδικά για τους μαθητές του **Γυμνασίου Νέας Ερυθραίας**. Καλύπτει τα τέσσερα βασικά διδακτικά πεδία των Φυσικών Επιστημών (**Φυσική**, **Χημεία**, **Βιολογία**, **Γεωγραφία**) για όλες τις τάξεις του Γυμνασίου (**Α΄, Β΄, Γ΄ τάξη**).

---

## 🎯 Παιδαγωγικοί Στόχοι & Φιλοσοφία

Η εφαρμογή αναπτύχθηκε με στόχο να προσφέρει στους μαθητές έναν ευχάριστο, άμεσο και αποδοτικό τρόπο εμπέδωσης της διδαχθείσας ύλης:
* **Αυστηρή αντιστοίχιση με τη διδακτέα ύλη**: Όλες οι ερωτήσεις βασίζονται αποκλειστικά στα επίσημα φυλλάδια αυτοαξιολόγησης και στις σημειώσεις του σχολείου.
* **Άμεση ανατροφοδότηση (Instant Feedback)**: Σε κάθε απάντηση, ο μαθητής ενημερώνεται άμεσα αν είναι σωστή ή λανθασμένη, συνοδευόμενη από επιστημονική και αναλυτική αιτιολόγηση επίλυσης.
* **Διδακτική υποστήριξη (Hints)**: Δυνατότητα εμφάνισης στοχευμένης υπόδειξης πριν από την τελική επιλογή.
* **Μηχανισμός Παράλειψης (Pass/Revisit)**: Ο μαθητής μπορεί να παραλείψει προσωρινά μια ερώτηση που τον δυσκολεύει και η εφαρμογή την επαναφέρει αυτόματα στο τέλος του κύκλου.
* **Αναλυτική Επισκόπηση (Review Screen)**: Με την ολοκλήρωση του τεστ παρέχεται πίνακας όλων των ερωτήσεων με τη σωστή απάντηση, την επιλογή του μαθητή και την πλήρη επεξήγηση για αποτελεσματική επανάληψη.

## 📱 Εργονομικός Σχεδιασμός & Βελτιστοποίηση για Κινητά (Mobile View)

Καθώς πολλοί μαθητές χρησιμοποιούν τα κινητά τους τηλέφωνα για μελέτη, η πλατφόρμα ενσωματώνει προηγμένη υποστήριξη αφής:

1. **Αυτόματη εμπειρία smartphone (οθόνες $\le 640\text{px}$)**:
   * **Sticky Bottom Thumb Bar**: Τα κουμπιά πλοήγησης (*«💡 Υπόδειξη»*, *«Παράλειψη»*, *«Επόμενο ➔»*) παραμένουν μόνιμα καρφιτσωμένα στο κάτω μέρος της οθόνης (στη ζώνη του αντίχειρα), εξαλείφοντας την ανάγκη συνεχούς κύλισης (scrolling).
   * **Μεγάλοι στόχοι αφής ($\ge 50\text{px}$)** με άμεση απτική απόκριση και αποτροπή καθυστερήσεων διπλού πατήματος (`touch-action: manipulation`).
   * **Αυτόματο Smooth Scroll**: Αυτόματη ομαλή μετακίνηση στην κορυφή κάθε νέας ερώτησης και στο πλαίσιο επεξήγησης.
   * **Οριζόντια κυλιόμενα breadcrumbs**: Συμπαγής πλοήγηση χωρίς περιττή κατανάλωση κατακόρυφου χώρου.

2. **Διακόπτης «📱 Κινητό» στο Menu (Desktop Phone Simulator)**:
   * Στην κορυφή της σελίδας υπάρχει ο διακόπτης **«📱 Κινητό»**.
   * Επιτρέπει στον καθηγητή να προσομοιώνει στον υπολογιστή του την ακριβή διάταξη και εμπειρία που βλέπουν οι μαθητές στα κινητά τους (iPhone/Android bezel), διευκολύνοντας τον έλεγχο και τη διδασκαλία.

## 💻 Τεχνολογική Αρχιτεκτονική

* **Client-Side SPA (Single Page Application)**: Κατασκευασμένο αποκλειστικά με Vanilla HTML5, σύγχρονο CSS3 και JavaScript (ES6+), χωρίς εξωτερικά βαριά frameworks ή βιβλιοθήκες.
* **Hash-based Routing (`#/class/...`)**: Εξασφαλίζει ομαλή πλοήγηση, υποστήριξη ιστορικού περιηγητή (Back/Forward) και πλήρη συμβατότητα με στατικούς διακομιστές.
* **Dark & Light Mode**: Εναλλαγή σκοτεινού και φωτεινού θέματος με αποθήκευση προτίμησης στο `localStorage`.
* **Μηδενικές Εξωτερικές Εξαρτήσεις**: Μέγιστη ταχύτητα φόρτωσης, ασφάλεια και απόλυτη αυτονομία.

## 🌐 Φιλοξενία στο GitHub Pages

Η εφαρμογή είναι πλήρως συμβατή με τη δωρεάν υπηρεσία **GitHub Pages**:

* **Σχετικές Διαδρομές (Relative URLs)**: Όλες οι συνδέσεις αρχείων (`assets/...`, `css/...`, `js/...`) είναι σχετικές, λειτουργώντας άψογα σε υποφακέλους αποθετηρίου (`https://<username>.github.io/<repo>/`).
* **Αρχείο `.nojekyll`**: Συμπεριλαμβάνεται στον ριζικό φάκελο ώστε το GitHub Pages να σερβίρει άμεσα όλα τα assets χωρίς επεξεργασία από το Jekyll.

### Ενεργοποίηση μέσω GitHub Web Interface:
1. Στο αποθετήριό σας στο GitHub, μεταβείτε στην καρτέλα **Settings** (Ρυθμίσεις).
2. Στο αριστερό μενού επιλέξτε **Pages**.
3. Στο πεδίο **Branch**, επιλέξτε `main` (ή `master`) και φάκελο `/(root)`.
4. Πατήστε **Save**. Σε 1-2 λεπτά η ιστοσελίδα είναι δημοσιευμένη στο διαδίκτυο.

## 🔒 Μελλοντική Απόκρυψη Σωστών Απαντήσεων

Σε ένα δημόσιο στατικό αποθετήριο GitHub, ο πηγαίος κώδικας JavaScript είναι προσβάσιμος. Για να αποτραπεί η εύρεση των σωστών απαντήσεων από μαθητές που γνωρίζουν ανάγνωση κώδικα, μπορούν να εφαρμοστούν:
1. **Κρυπτογραφικό Hashing (SHA-256)**: Αποθήκευση μόνο των hashes των σωστών επιλογών αντί για απλούς αριθμητικούς δείκτες (π.χ. `correctHash: "a6c5..."`), καθιστώντας αδύνατη την άμεση ανάγνωση.
2. **Minification & Obfuscation**: Συγχώνευση και κωδικοποίηση του script πριν το τελικό push.

## ⌨️ Συντομεύσεις Πληκτρολογίου (Desktop)

* <kbd>1</kbd> έως <kbd>5</kbd>: Άμεση επιλογή απάντησης (Α έως Ε)
* <kbd>H</kbd>: Εμφάνιση / Απόκρυψη υπόδειξης (Hint)
